# Introduction

Voxalfa is a declarative, line-based language for composing and storing [tonic sol-fa](https://en.wikipedia.org/wiki/Tonic_solfa) scores. It aims to keep scores compact and readable while remaining regular enough to be parsed, formatted, highlighted, and generated by tools. The reference implementation is developed in the [voxalfa repository](https://github.com/voxalfa/voxalfa).

A Voxalfa file can be converted to MIDI, SVG, and PDF; MusicXML support is planned.

## Highlights

- **Declarative:** a score describes what should be played, not how to draw it or how to schedule individual events.
- **Line-based and directive-driven:** declarations are written one line at a time and start with an explicit marker.
- **Typed:** metadata and parameters have well-defined types, so mistakes are reported by the compiler.
- **Composable and highly flexible:** sections, sub-sections, repeats, jumps, and timed dynamics make it possible to describe complete scores, and the language even supports per-voice lyrics.
- **Complete language toolchain:** a parser, formatter, validator, language server, and score renderers provide editor support, diagnostics, and output generation.
- **Text-first:** scores are plain text, so they are easy to version and diff, friendly to large language models, and can be generated from existing sheet music provided as images or PDFs.

## A minimal score

```voxalfa
;; @version 0.1.0-alpha
;; @note-text font-size={12}

[#] title="Hello, Voxalfa"
[#] author="Voxalfa"
[#] verses={1}

[$] key={C} | time={4,4} | tempo={100} | voices={S,A}

---

[$] label="Verse" | mark={S}

[$] dynamics={p:0, cre:1..3, f:3}

[S] |d :r !m :f ||
[A] |d :r !m :f ||

[1] do re mi fa @@

--

[$] key={G} | tempo={110} | jump={DS}

[S] |s :l !t :d+1 ||
[1] so la ti do

++

[A] |s :l !t :d+1 ||
[1] la ti do re
```

Voxalfa is still in early development. Syntax and features may change before the first stable release.
